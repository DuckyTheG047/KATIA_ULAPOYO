# Guía de Programas UL — GitHub Pages

Sitio estático listo para GitHub Pages. El archivo `index.html` es una copia exacta del HTML original, sin cambios visuales ni funcionales.

## Publicar
1. Sube `index.html` y `.nojekyll` a la raíz de tu repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige **main** y **/(root)**; guarda.
5. Abre la URL que GitHub muestre en Pages.

La aplicación utiliza `localStorage` para guardar progreso en el navegador de cada visitante; no es una base de datos compartida ni captura leads en un servidor.
